## Reproducible data tooling

The tools/seed-demo.mjs script defaults to a dry run. Install its dependencies with npm install from my_app/tools. Supply administrator application-default credentials, then run from my_app:

```powershell
node tools/seed-demo.mjs --project=cls055-26-project
```

Adding --apply --credentials=LOCAL_FILE.json --manifest=LOCAL_MANIFEST.json writes the demo data. This has already been done: do not rerun it on the populated project unless intentionally resetting demo data. It refuses to replace demo events with recorded live attendance changes. A Firebase CLI credential adapter is available through --firebase-cli-lib=PATH_TO_FIREBASE_TOOLS_LIB for an already authenticated local CLI; no CLI credentials are included in this ZIP.

To run backend rule tests independently, install dependencies under my_app/tools/firebase-tests and run npm test there. The configuration uses a demo emulator project; the test suite loads firestore.rules directly and does not use the live project.
